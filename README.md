# Bruns Timer 60

Ein Timer im Stil der klassischen Wecker nach Dieter Rams.
Eine einzige HTML-Datei. Keine Abhängigkeiten.

## Funktionen

- Rundes Zifferblatt mit gelbem Zeiger und oranger Restzeit-Fläche
- Schiebeschalter: Stunde (60 Minuten) oder Minute (60 Sekunden)
- Schieberegler: stellt die Laufzeit ein, 1 bis 60 Minuten oder 1 bis 60 Sekunden. Ziehen, Tippen, Mausrad oder Pfeiltasten.
- Orange Taste: Start und Stopp
- Graue Taste: Zurücksetzen
- Signalton und Vibrationsalarm, wenn die Zeit um ist. Beide wiederholen sich bis Start oder Reset.
- Bildschirm bleibt an, solange der Timer läuft
- Darunter das Wetter für Oldenburg in Oldenburg: aktueller Stand mit allen Messwerten, Tagesverlauf und sieben Tage.
  Quelle ist der Deutsche Wetterdienst über die offene Schnittstelle Bright Sky.
- Timer und Wetter füllen je eine volle Bildschirmhöhe. Die Seite rastet beim Scrollen ein.

## Nutzung

`index.html` im Browser öffnen. Oder über GitHub Pages aufrufen.
Auf dem Telefon: Seite öffnen und „Zum Home-Bildschirm“ wählen.
Dann startet der Timer randlos wie eine App, auf Android im Vollbild.
Im Browser schaltet Android beim ersten Antippen auf Vollbild.

Hinweis: Der Ton kommt nur, solange die Seite offen ist.
